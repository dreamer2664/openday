# Screenshot · file unico e telefono

Sei screenshot reali del nuovo HTML LPC in Chromium, rigenerati dal test `scripts/standalone_ui_test.py`: benvenuto offline, creatore desktop, anteprima fotografica, creatore touch, anteprima NES e salvataggio touch. Sono JPG per ridurre il pacchetto; non sostituiscono i PNG HD reali in `renders/`.

La modalità touch è **emulata**, non un telefono fisico. Il file è stato aperto `file://` con rete disattivata. È stato provato anche `/telefono`, caricato inizialmente via HTTP e poi usato offline fino all’export. Nessuna prova nativa iOS/Android, Safari/Firefox o Web Share è implicata.

Hash dell’HTML e risultati in `docs/test-results/standalone-browser-tests.json`. Tutti i nomi/configurazioni sono sintetici.

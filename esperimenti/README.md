# Esperimenti — NON RELEASE

Questa cartella archivia il lavoro prodotto durante l’audit, senza applicarlo alle versioni Deluxe o PC.

- `canvas/Cartolina_Casardi_CANVAS_SPERIMENTALE.html`: prototipo completo e autonomo. Evita encode/decode PNG nel preview e consente nuovi gesti mentre una rifinitura precedente è pendente. Sorgenti modificati, patch e prova di build accanto al file.
- `http/`: candidata di correzione per la proprietà delle richieste nell’edizione Flask/HTTP; non applicata alla produzione e non è la diagnosi del caso Arena.

**Nessuna di queste varianti è una correzione confermata del blocco Android/Arena.** La Deluxe richiesta dall’utente è invece l’HTML completo 3.3.1 nella radice del branch.

Rapporto: [Analisi del blocco](../Analisi_blocco_Android_Arena.md). Le verifiche riuscite, fallite e incomplete sono tutte conservate nel dossier di diagnostica.
